# 界面方向

2026-10-17：Vana 是一个给文字工作者玩的写作玩具。普通正文页保持清晰，主动打开的文字工坊提供更丰富的材质、排版和视觉表现。继续使用 Vite / React / Tiptap 与现有四主题。

- 正文占主位；目录、编辑/阅读切换与修改记录保留直接入口，文字冲印与信稿从文件菜单或更多文档操作进入。
- 工坊以作品预览为中心，控制项按介质、文字、痕迹展开。效果由介质决定，控制位置、范围、方向和浓度，不展示渲染实现细节。
- 桌面预览与控制项并列；手机使用全屏工坊，预览与控制项可滚动，底部保存和分享操作固定可见。
- 画面点按和拖动提供直观操作，同时保留按钮与滑块，支持键盘、撤销、重做和减少动画偏好。
- 创作内容嵌入正文，可再次调整信稿；插入前仅缓存本次制作，也可显式导出配方。Android 正文保留系统选择工具栏与选区手柄，不用网页浮层覆盖文字。不要用“已保存”暗示尚未持久化的状态。
- 账号继续独立成页；设置提供外观、备份与高级选项。队列、额度、会话与服务状态只在按需展开的诊断中显示。
- 保存失败、同步失败、文字超出画幅、凭据不可用和删除恢复风险应给出可行动的反馈；无异常时不解释内部实现。

此前账号和全局界面参考 React Bits 的 Fade Content 与 Animated List，见 [界面优化](archive/UIUX_REFINEMENT_2026-10-13.md) 与 [第三方声明](../THIRD_PARTY_NOTICES.md)。信稿的纹理和效果由本地 Canvas 绘制，两款专用字体随应用打包，不依赖远程素材服务。
