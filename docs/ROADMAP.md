# 开发路线

当前候选版本为 0.7.1，正式公开版为 0.7.0。最新版体验包已完成 OnePlus 验收，用户随后在 Pixel 9a 上实际操作并确认没有明显问题；上线前清理和复检见 [发布自检](RELEASE_READINESS_2026-10-15.md)。

## 当前优先级

1. 完成候选版本的自动化、构建、签名及平台验收，整理更新说明与实际功能边界。
2. 发布后关注查找文档、继续编辑、保存反馈与手机布局的实际使用问题，优先修复影响日常写作的缺陷。
3. 修改记录与备份继续作为按需使用的恢复入口，同步在前台自动执行；工程诊断保留在高级选项中。

不凭存储模块进度扩展产品功能。附件实验停留在 `feat/local-attachments`，不进入本次候选版本；云附件、多人权限、实时协作和端到端加密仍不承诺上线。

## 维护约束

保存、恢复和同步必须保留账号空间校验、内容代次、事务 outbox 与冲突副本。发布检查不能用模拟 IPC 替代原生设备，也不能用 Debug 签名包替代正式签名升级验收。旧用户数据库和备份不得因代码清理而删除。

设计基线见 [产品方向](PRODUCT_DIRECTION.md)、[架构](ARCHITECTURE.md) 与 [UI 方向](UI_DIRECTION.md)。原技术工作包和阶段性证据在 [历史路线](archive/ROADMAP_2026-10-13.md)，不再作为默认开发待办。
