# 开发路线

Vana 是给文字工作者玩的写作玩具：文字写得顺手，也能通过组件、介质和自定义拥有好玩的形式。0.8.0 以文字冲印与信稿工坊开启功能扩展阶段，产品取舍见 [产品方向](PRODUCT_DIRECTION.md)。

## 0.8.x：增加新功能

0.8.0 交付可嵌入正文、再次编辑的信稿组件：五种介质、四种字体、三种画幅，以及按介质呈现的血迹、烧焦、损毁与污渍；支持图层、撤销重做、PNG 分享和可重新打开的信稿配方。桌面选区菜单与 Android 系统文字选择菜单均可进入工坊。实现与验证边界见 [信稿工坊](LETTERPRESS_STUDIO.md)。

后续小版本优先围绕实际试玩反馈扩展，每次完成一个可以制作、保存、再次编辑和分享的完整玩法：

- 优先考虑个人预设，让常用排版、介质和痕迹组合可以保存与复用。
- 增加有辨识度的文字组件，例如角色留言、对话片段或世界观档案；具体组件在开发前确定，不把候选清单全部当作交付承诺。
- 按作品需求扩充介质、痕迹和自定义选项，保持不同材质下的组合合理。

0.8.x 仍修复日常使用问题、维护保存与恢复。用户字体导入、多页排版和外部图片材质按反馈评估，尚未承诺纳入 1.0。

## 0.9.x：最后一轮前端界面优化

收敛功能范围，围绕已交付玩法统一布局、主题、字体、动效和交互。重点检查手机触控、系统选择菜单、键盘遮挡、窄屏、长文、加载与错误恢复；普通阅读与编辑保持清晰，减少动画偏好得到尊重。

这一阶段主要打磨已有功能，不再大幅增加新的组件或制作流程。完成三个平台的安装、导出、分享、升级与数据保留回归，修复阻碍 1.0 的问题。

## 1.0.0：正式发布

正式发布以体验和可靠性验收为准，不以功能数量为准：

1. 新用户可以从一段文字独立制作、保存并分享作品，重开后能继续调整。
2. 主题与组件风格统一，手机、桌面、中文排版和常见异常都有可用的处理。
3. 原有正文、信稿、修改记录、备份与可选同步在升级后保留且可恢复。
4. 正式签名安装包完成平台验收，GitHub Release 与官网下载清单一致，已知限制清楚可查。

## 维护约束

保存、恢复和同步保留账号空间校验、内容代次、事务 outbox 与冲突副本。发布检查不能用模拟 IPC 替代原生设备，也不能用 Debug 签名包替代正式签名升级验收。旧用户数据库和备份不得因清理而删除。

附件实验仍停留在 `feat/local-attachments`，多人权限、实时协作和端到端加密没有上线承诺。工具链升级与格式整理独立处理。

设计基线见 [架构](ARCHITECTURE.md) 与 [UI 方向](UI_DIRECTION.md)，发布规则见 [版本与分支](VERSIONING.md)。
