# 产品方向

2026-10-17：用户明确将 Vana 定位为一个给文字工作者玩的写作玩具。可以随手记事，也可以为几句话挑选字体、介质和痕迹，把文字制作成值得分享的作品。趣味、表达张力和便利是开发主线；离线保存、恢复与可选同步支撑这个体验。

## 希望建立的长处

Vana 希望让短文、虚构书信、世界观片段和角色留言拥有自己的形式。作品本身可被带走：一张分享卡、一封烧焦的信、一段碎屏上的遗言。

0.8.0 的首个组件是文字冲印与信稿工坊：文档或选中文字进入工坊，选择介质、排版和痕迹，插入正文成为可再次编辑的内容块，也可导出图片分享。效果按介质解释，纸上的撕裂、石碑的崩裂和终端的碎屏各有表现。实现与边界见 [信稿工坊](LETTERPRESS_STUDIO.md)。

## 功能取舍

- 优先能够直接试玩、组合和分享的小功能；先做好一个完整玩法，再增加新组件。
- 自定义应帮助表达：字体、留白、纹理、层次、位置、方向和浓度；不把内部渲染参数变成用户负担。
- 特效留在主动打开的创作空间。普通阅读和编辑仍清晰，尊重减少动画偏好。
- 保存、恢复、备份与同步继续维护；工程诊断、队列和额度等留在高级选项。
- 多人权限、实时协作、云附件和端到端加密没有交付承诺；不因模块已有代码而自动扩张产品范围。

## 到 1.0 的判断方式

1. 新用户能从一段文字独立做出作品，能理解控制项，并顺利导出或分享。
2. 介质与效果的组合有辨识度，重复打开配方能继续制作，叠加不会破坏已有图层语义。
3. 手机操作、中文字体、长文溢出和导出失败都有清晰可用的处理。
4. 正式签名安装包完成真机分享、升级和数据保留验收，现有保存与恢复能力不回退。

0.8.x 增加新的文字组件、视觉效果和自定义能力，以实际试玩反馈决定次序；0.9.x 收敛功能范围，完成最后一轮前端界面与交互优化；随后通过上述验收，发布 1.0.0。具体阶段目标见 [开发路线](ROADMAP.md)。
