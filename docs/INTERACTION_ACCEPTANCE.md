# 交互改造验收 · 2026-11-14

当前为 0.8.x 开发体验包，尚未公开发布。已在 USB Pixel 9a / Android 17 上覆盖更新独立 Preview；未使用安卓模拟器。详细设备过程与限制见 [移动界面调整](MOBILE_UI_REFINEMENT.md)。

| 原始要求 | 交付结果 | 验证依据 |
| --- | --- | --- |
| 模块独立编辑 | 对话卡和信稿默认渲染；模块长按 / 右键菜单；独立编辑、复制、复制模块、转正文、删除；信稿直接分享 | 浏览器 15 项模块断言；原生持久化测试；Pixel 独立编辑与冷启动回读 |
| 下拉菜单审查 | 顶部菜单、正文菜单、文档树菜单、模块菜单、工坊文件菜单、所有网页选择字段统一 SVG、边界定位、进入 / 退出、焦点与键盘 | 四种宽度 × 四组菜单检查、嵌套 Escape、选中项聚焦、减少动态设置；设备系统选字菜单继续使用原生实现 |
| 移动端层级移动 | 触摸激活分组 / 文档；独立目标浏览、根目录、明确确认、失败重试；排除自身、子树、不同状态 / 空间及超深目标 | 2 项移动边界单测；6 项浏览器流程断言；Pixel 文件移入、分组携子文档移动、移回根目录、覆盖升级后回读 |
| 文字工坊重整 | 新建空白、固定画布、浮动参数面板、可拖动入口、100%–200% 缩放、手势互斥 | 2 项视口数学单测；20 项浏览器工坊断言，包含 320×640、390×844、768×360、1440×900、390×440；Pixel 真正双指注入、绘制与嵌入、系统分享 |
| 主要交互动效 | 菜单、模态框、分享 / 属性面板、展开区、通知、工坊参数页与画布复位补齐过渡；退出惯性区域不可操作；减少动态适配 | 浏览器退出与动态偏好检查；保留既有设置 / 账号 / 帮助 FadeContent，不在可编辑正文上运行装饰动画 |
| React Bits 调研供选择 | 固定官方源码版本，对 8 项候选说明场景、依赖、触控 / 性能 / 动态偏好适配；未自动接入 | [候选清单](REACT_BITS_CANDIDATES.md)，建议从 ClickSpark 与 PixelTransition 中选择 |

40 项前端单测、36 项原生核心测试、TypeScript、生产网页 / Android APK 构建和差异空白检查通过。浏览器共 96 项交互断言（含修正后的模块按钮遮挡检查）。浏览器使用模拟 IPC，真实设备结果单独记录，未将其作为云同步或公开发布验收。

本地可复核资料：`output/interaction-refinement/` 中的单元测试、原生测试、类型检查、构建日志、`browser-*-results.json`、`module-overlap.log`；`pixel-9a/` 中的安装、模块、工坊、移动、选择菜单、清理和健康结果，以及 APK 与校验和。测试原文曾因重启选中欢迎文档而被插入信稿，已撤销该插入并在最终包核对原文恢复；所有测试树均已移入回收站。
