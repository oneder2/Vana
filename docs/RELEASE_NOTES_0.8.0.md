# Vana 0.8.0 — 让文字拥有好玩的形式

文字冲印与信稿工坊加入正文：把几句话做成卡片、一封旧信、一块石碑、一页奥术残稿或终端上的消息，再插入文档，随时打开继续调整。

- 五种介质、四种字体、三种画幅，可调整标题、正文、落款、字号、行距与留白。
- 血迹、烧焦、撕裂 / 崩裂 / 碎屏与污渍按介质呈现；支持方向、范围、图层顺序和撤销重做。
- 细化纸纤维、纸浆色差、折痕、焦边与灰屑，以及石刻、符文和玻璃质感。底部操作栏与预览底色跟随主题。
- 信稿以可编辑内容块保存，跟随文档的修改记录、空间备份和可选同步；PDF、DOCX 导出保留作品图片，Markdown 保留信稿配方。
- 支持 PNG 图片分享和可重新打开的信稿 JSON。桌面选区菜单增加“文段分享 / 制作信稿”，Android 使用系统原生文字选择菜单。
- 修复在纸张边缘或烧穿区域绘制后光标卡住的问题。

打开文档的“更多文档操作 → 文字冲印与信稿”，或选中文字进入制作。完成后点击“插入文档”，通过块下“调整信稿”继续编辑。

升级前建议在设置中导出空间备份。**0.7.x 不支持新信稿内容块，请将使用同一文档的设备升级到 0.8.0 后再同步含信稿的文档。** 本次无需数据库迁移。Android 正式包沿用原签名；Preview 是独立体验应用。Windows 安装包沿用项目自签名证书，系统可能提示未知发行者。

Vana 仍处于 Beta 阶段：0.8.x 增加新功能，0.9.x 完成最后一轮前端界面优化，随后发布 1.0.0。[详细路线](https://github.com/oneder2/Vana/blob/main/docs/ROADMAP.md)。
