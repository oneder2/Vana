# 文档文字组件

以下文字组件纳入 0.8.1。

## 角色对话卡

在文档中打开「插入 → 角色对话卡」。选中几行文字再插入时，会复制选区；`旅人：灯还亮着吗？` 这样的行会拆成角色名和台词，原文保留。

卡片默认展示渲染结果。长按、右键或右上角操作菜单选择「编辑对话卡」，再改角色、写台词、增删台词；点击「完成」回到展示。一篇文档同时只编辑一张对话卡。「样式与预设」可切换聊天气泡、剧本或访谈记录，调整字体和间距。卡片外的正文始终可以直接编辑，组件样式在独立编辑状态下展开。菜单还提供复制文字、复制模块、转为正文与删除；复制、转换、删除支持编辑器撤销。选择「转为普通正文」可恢复普通段落，保留标题、角色名、台词和正文格式。

对话卡随文档保存，参与修改记录和空间备份。Markdown 导出为普通段落；DOCX 与原生 PDF 导出保留标题、角色名和可选择的台词，版式会随文件格式简化。

## 个人预设和灵感骰子

对话卡的「样式与预设」和信稿工坊的「预设」都能收藏当前样式。预设只保存外观，按当前空间保存在本机，不随空间备份或同步。应用预设后，文档会保存实际使用的样式，删除预设不影响已有文档。

灵感骰子会换一套外观，标题、正文、落款和角色台词保持原样。先勾选要保留的项目再掷骰；信稿默认锁定画幅。对话卡使用编辑器撤销，信稿使用预览上方的撤销按钮。

## 剧情判定

从「插入 → 剧情判定」进入。填写问题和 2 至 12 个结果区间，每个点数从 1 到 100 都需分配给一个结果。可以先保存表格，或点「掷骰并记录」立即掷 1D100。记录包含点数和当时命中的结果。展开「查看判定表」可检查区间，点「继续写作」可回到下方正文。卡片菜单里的「复制为新判定」复用问题和表格，复制件等待新的掷骰。

卡片随正文参与修改记录、备份和同步，文本导出包含问题和结果。0.8.1 之前的客户端需要升级才能处理含剧情判定的正文。

## 兼容性与验收

新增对话卡不需要数据库迁移。0.8.0 客户端不支持这一正文节点，使用同一文档的设备需升级到支持对话卡的版本后再同步。

开发验收覆盖浏览器中的编辑、撤销和重开，以及原生存储层的保存、历史恢复、备份导入和同步数据收发。浏览器流程使用模拟原生命令。

OnePlus 7 Pro（Android 13）已使用同一测试签名将独立 Preview 从 0.7.1 覆盖升级到 0.8.0 开发包。访客模式下验证了对话卡插入、台词编辑、锁定字体后掷骰、保存预设、重启后回读正文和应用预设。这是本轮手机界面调整之前的验收记录，本轮结果见 [移动界面调整](MOBILE_UI_REFINEMENT.md)。
