# Vana 0.8.1 · 剧情判定

在文档里选择「插入 → 剧情判定」，写下角色遇到的问题，再为 1 至 100 的骰点划分结果区间。可以先保存判定表，也可以当场掷骰并记录。卡片收起时显示问题、点数和命中结果，点击「继续写作」把光标移到卡片下方。需要再次使用同一张表时，从卡片菜单选择「复制为新判定」。

判定表默认有三个区间，可改成 2 至 12 条。掷出的记录跟随正文保存、同步和备份。Markdown、DOCX 和 PDF 导出保留问题、点数和命中结果。

- 新增角色对话卡，支持气泡、剧本和访谈样式，可在正文中编辑和复制。
- 信稿和对话卡可收藏个人预设，使用带锁定选项的灵感骰子切换样式。
- 文字工坊支持固定画布、双指缩放和可拖动的参数入口。新建信稿从空白开始，选区入口带入所选文字。
- 手机常用操作集中在两行顶部栏，选字时显示底部格式栏。文档库侧栏加入收藏筛选，移动文件和分组时可逐级选择目的地。
- Linux x86_64 可使用本机脚本安装正式版，配置登录桌面自启和定时更新。详见 [Linux 本机安装](LOCAL_DESKTOP.md)。

使用同一篇含剧情判定或对话卡的文档时，请将参与同步的设备都更新至 0.8.1。升级前可在设置中导出空间备份。
