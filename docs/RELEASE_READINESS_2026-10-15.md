- 开启未使用变量和参数检查；统一 6 处版本/锁文件为 0.7.1；版本脚本验证输入后再写入。

## 需要明确的边界

- 完整 npm 审计仍有 7 项开发工具链告警（5 high、2 moderate），位于 Tailwind 3 的扫描和 CSS 构建依赖。兼容升级已应用，npm 给出的完整修复要求迁移 Tailwind 4；本次没有临上线强制跨大版本迁移。这些包不打入应用运行时代码；构建告警仍需后续解决。
- Windows 使用项目自签名证书，不承诺系统认可发行者；签名完整性与公共信任是不同验收项。
- 云端验收使用管理员生成的确认链接，没有验证邮件供应商投递和收件箱。
- 之前 OnePlus 图标/交互及 Pixel 9a 用户体验记录对应 0.7.0 Preview。0.7.1 的新签名产物与设备验收须单独记录，不沿用旧结论。
- 本次无新数据库迁移；未清除现有用户文档、账号或正式安装包。
