# 移动写作界面调整（开发版）

本轮属于 0.8.x 开发分支，尚未公开发布，不修改 0.8.0 的发布记录。

## 操作变化

- 手机常态顶部为两行：返回、所在分组、文档标题、分享及账号合并为第一行；第二行保留文件、编辑、插入、样式、帮助、设置。
- 点标题打开文档属性上拉面板：完整路径、修改记录、同步副本、更新时间及标签。
- 去掉用户切换的阅读模式，打开正文即可编辑，仍自动保存。查看历史或同步副本时临时保护背景编辑器。
- 只有选中文字时显示底部格式栏，光标输入或编辑组件名称时隐藏。保留 Android 系统选择菜单与选区手柄，格式栏根据可视视口避让键盘。
- 文字冲印与信稿、角色对话卡均从“插入”进入；个人预设和灵感骰子在组件的样式操作中使用。后续文字组件继续使用这一入口。
- 菜单、文档库、属性面板、格式栏采用短暂的透明度/位移动效；按钮有按压反馈，尊重系统减少动态效果设置。

## 验证

前端单元测试 36/36、TypeScript 检查通过；Android 构建执行生产前端打包。浏览器流程使用模拟原生命令，验证默认可编辑、自动保存、选区格式栏、加粗、属性路径与历史、插入组件、元数据编辑和重载回读。

320/390/768 像素宽度检查页面、菜单、面板及格式栏边界；1440 像素桌面检查保留顶部格式栏和插入菜单。检查减少动态效果、面板焦点循环、退出后卸载。浏览器结果使用模拟 IPC，真实键盘和选区结果见下文。

本轮测试账号通过真实 Supabase 密码登录和本人文档快照读取验证，私人凭据留在本机 secrets 目录，不纳入源码或测试报告。账号已在 OnePlus 登录，自动拉取了预先建立的试玩指南；从手机插入角色对话卡后，使用账号 JWT 从云端快照读回确认了上行同步。

真机发现旧 Android 窗口使用 `adjustPan`，会遮住底部工具。窗口改为 `adjustResize`，原生边距监听处理并消费键盘 inset，使 WebView 的实际可用高度随键盘变化；浏览器仍使用 visualViewport 兼容覆盖式键盘。

## OnePlus 真机验收

OnePlus 7 Pro / Android 13 使用同一测试签名覆盖升级独立 Preview，首次安装时间保持不变；正式应用未改动。实测属性上拉面板与修改记录、插入对话卡、组件标题输入时隐藏格式栏。长按保留系统文字选择菜单和手柄，格式栏位于键盘上方；点击加粗保留选区，点成光标后收起，关闭键盘后恢复 WebView 高度。

键盘显示时 WebView 的物理坐标为 `[0,128]–[1440,2098]`，格式栏为 `[199,1909]–[1242,2074]`，未被键盘覆盖。关闭键盘后 WebView 恢复至底部 3037px。证据保存在本机 `output/mobile-refinement/`，包含构建、签名、安装、浏览器与真机记录；不随源码发布。

覆盖升级和冷启动后，账号仍登录，试玩指南与对话卡标题回读成功；手机端的加粗修改也已通过独立账号 JWT 从云端读回。测试结束时手机停留在该账号的试玩指南，键盘收起。

## 文档库与操作菜单后续调整

侧栏筛选为「文档库 / 收藏 / 回收站」，移除「最近」与重复的收藏分区。使用单一列表展示当前筛选；收藏包含各级分组中的有效收藏文档，不再限制为六条，支持标签筛选和取消收藏后刷新。普通文档库仍按目录层级浏览。

顶部操作和下拉条目使用 Lucide SVG 线条图标。下拉面板挂载到页面顶层，根据触发按钮实际坐标定位，随窗口或可视视口变化调整位置，靠近边缘时限制宽高并允许滚动。避免固定顶部偏移和祖先变换造成错位。面板内点击、外部关闭、Escape 归还焦点和方向键导航均保留。

浏览器通过 320/390/768px 以及 390×300px 短屏的四组菜单边界检查，展开后与按钮下缘间隔 4px；1440px 桌面定位检查通过。模拟原生命令验证了八条跨分组收藏、标签筛选、排除回收站/归档及取消收藏。前端 36 项测试与类型检查通过。

新版已覆盖安装 OnePlus Preview。真机复核文件、编辑、插入、样式四个菜单的位置与图标，以及收藏操作、收藏筛选和打开文档；「最近」入口与重复收藏块均已移除。新增真机证据位于 `output/library-menu/android/`。

2026-11-14 在 USB 连接的 Pixel 9a / Android 17 上复核当前工作区的 0.8.0 Preview，未使用 Android 模拟器。安装前比对原包签名，使用 `adb install -r` 覆盖升级；首次安装时间保持不变，并核对 APK 内嵌的前端资源与本次构建一致。四个顶部菜单的首项均位于触发按钮下缘 24 个物理像素处（含面板内边距），右侧菜单避让屏幕边缘；SVG 图标、返回键关闭、切换菜单和重复点击收起均通过。新建测试文档验证了收藏、打开、进程重启后持久化与取消收藏后立即移除。证据位于 `output/library-menu/pixel-9a/`。

定位细节：顶部菜单按钮按下时不缩放，避免读取到暂时变化的锚点坐标；向上展开时将面板边框计入高度，按完整菜单高度选择展开方向，并限制在可视视口内。删除旧菜单定位与动画样式，统一使用共享浮层。


## 2026-11-14 模块编辑、移动与文字工坊

- 对话卡默认显示渲染结果，长按 / 右键 / 操作按钮进入模块菜单；选择编辑后才出现字段、样式和台词操作，完成后回到展示。输入区保留原生选字操作，滚动和双指操作不触发长按菜单。信稿默认展示 Canvas，编辑原块和直接分享图片为独立操作。
- 所有网页下拉操作统一使用 `FloatingPanel / ActionMenu / SelectField`：SVG 图标、进入 / 退出过渡、边缘定位、退出时 inert、方向键导航与焦点归还。搜索、重命名、移动、分享、替换、历史和同步副本面板补齐受控退出；帮助 / 高级设置 / 样式说明采用可收放展开区。Toast 自动关闭与手动关闭使用同一退出过渡。
- 触屏点击文件 / 分组直接激活，桌面鼠标拖动保留。移动使用独立目标浏览器，支持逐级进入、返回、根目录和明确确认，排除自身、子树、不同空间 / 状态和会超过原生 7 层上限的目标。等待移动期间禁用重复确认和关闭，失败保留目标并提示；实际数据库仍再次验证。
- 从插入菜单创建信稿默认空白。工坊用固定画布与浮动参数面板，参数分页，展开不压缩画布；悬浮球支持拖动和键盘移动。画布适应窗口，缩放限制 100%–200%，放大浏览时可平移。双指开始时取消未完成痕迹，绘制缺口和越界释放后可继续操作。
- 本轮没有加入新的 React Bits 装饰组件。已根据官方固定版本源码整理 [候选效果与适配成本](REACT_BITS_CANDIDATES.md)，等待产品选择。
