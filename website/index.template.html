从安装到第一篇文档

开始使用

选择系统，查看安装说明。

在 Windows 上安装+

下载 EXE 安装程序并运行，按提示完成安装。也可以使用 MSI 安装包。

当前版本使用项目自签名证书，Windows 可能提示未知发行者。请先确认文件来自本官网链接的项目 Release，并核对校验信息。

在 Android 上安装+

下载 APK 后打开文件。如果系统阻止安装，按提示允许当前浏览器或文件管理器安装应用，完成后可关闭此权限。

后续下载正式版 APK 可覆盖升级，保留应用数据。Preview 测试包是独立应用，请继续使用与你已安装版本对应的渠道。

在 Linux 上安装+

AppImage 下载后，在文件属性中允许作为程序执行，再打开。也可以在终端运行：

chmod +x Vana_*.AppImage

Debian / Ubuntu 可选择 DEB；Fedora 等系统可选择 RPM。缺少运行依赖时，请查看 项目安装文档。

文档、账号与更新+

本地文档无需登录即可读写。跨设备同步需要账号和可用的同步服务；当前不提供实时协作、云附件或后台常驻同步。

正文修改记录仅恢复正文，不恢复历史标题、标签或目录。文档与备份为明文，当前不提供端到端加密。

升级前请导出空间备份，并阅读对应版本说明。官网始终指向最新正式发布版本，不自动安装更新。
