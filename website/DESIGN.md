# Vana 官网设计

读者是希望在电脑与手机上读写个人文档的人。页面的任务是让人理解 Vana，并下载适合设备的正式版本。

配色：雾蓝纸面 `#edf2f7`，白纸 `#ffffff`，墨蓝 `#243145`，紫色书签 `#62518d`，辅助墨色 `#657186`，淡蓝边界 `#d3deeb`。展示标题和示例正文用宋体 / Noto Serif CJK / Georgia；界面说明用系统无衬线；版本与平台用系统等宽字体。不开启远程字体加载。

布局：页首品牌与下载导航；左侧大字号用途描述，右侧一页文档和可切换的修改对照；下方三条能力说明，接平台下载列表和折叠安装帮助。手机改为单列，下载锚点始终直接可达。

```text
[图标 Vana]                       [安装帮助] [GitHub] [下载]

 把文字留下，                  ┌ 文档示意 / 修改对照 ┐
 把思路接上。                  │ 周末的一页          │
 简介与下载入口                │ 正文 + 修改痕迹     │
                               └────────────────────┘
 本地写作            回看改动             带走文档

 下载 Vana       版本 / 发布日期
 Windows         安装包 →
 Android         APK →
 Linux           AppImage → / deb / rpm

 安装帮助与版本说明
```

记忆点是一页可翻看修改痕迹的文档，直接表现产品的读写和追溯能力。评审时移除了装饰粒子、功能卡片墙和夸大同步能力的标语；所有下载链接来自正式 Release，同步限制放入相关说明。交互示意明确标注，避免被理解为正式版截图。无 JavaScript 时仍能下载和查看安装帮助。
