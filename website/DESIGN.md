# Vana 官网设计 · 流光中的一页

对象是希望在电脑和手机上保存、继续书写个人文档的人。页面任务是用一个可操作的文档示意讲清读写与修改记录，然后直接下载适合设备的正式版本。

## 设计计划

配色：夜蓝底 `#080d1b`，深蓝表面 `#111b30`，雾白文字 `#eff5ff`，青色光线 `#82eee3`，鸢尾紫 `#a397ff`，辅助蓝灰 `#aab8cf`。文档内页沿用雾白，让文字与深色外壳形成对比。光线来自应用图标的青紫配色。

字形：主标题用系统中文黑体，紧凑粗体、64–76px；示例正文用宋体 / Noto Serif CJK / Georgia，保留书写的温度；导航与说明用系统无衬线；版本与日期用系统等宽字体。不加载远程字体。

布局：全幅极光舞台包含两列首屏，左侧标题与下载，右侧倾斜悬浮的文档窗口。下方为三列能力说明、横向平台下载列表和折叠帮助。手机改为单列，取消倾斜，保留较低分辨率极光。

记忆点是一页漂浮在极光里的文档，文档的青紫边缘将背景光线与正文修改痕迹连起来。改编 React Bits Aurora 的实际 WebGL 着色器；卡片沿用 SpotlightCard 的指针聚光机制；标题按行进入，能力区滚动显现。所有动效只增强静态页面。

## 实施前评审

取消终端状态条、模拟运行指标和无关粒子，避免科技风变成与文档无关的仪表盘。以可阅读、可点击的文档为主角；下载采用整齐列表，避免全页卡片墙。绚丽集中在首屏，正文区域用克制的分隔线。交互示意标注始终可见，不冒充正式版截图。

## 行为要求

无 JavaScript 仍能下载和查看安装帮助。减少动画偏好或用户关闭动效时，不运行持续渲染、漂浮或视差。标签页隐藏、首屏离开视口时停止极光绘制；限制到 30fps 与最高 1.25 DPR。WebGL 不可用时显示 CSS 静态光晕。触屏不启用鼠标倾斜，键盘焦点明确可见。

## 浏览器评审

桌面使用两列首屏，手机将文档窗口放在下载按钮之后；取消手机悬浮倾斜，保持正文可读。最终检查保留了沿文档舞台移动的两条细流光，降低卡片聚光强度，避免与极光争夺注意力。六个宽度（320 / 390 / 560 / 768 / 1024 / 1440）无横向溢出。严格 CSP 下聚光正常，无新增策略违规；真实 WebGL 着色器绘制和时间推进已验收。手动暂停与持久化、离屏暂停/回来恢复、动态切换减少动画、无 JS 和无 WebGL 退路均通过。截图取静止帧用于检查布局，不能用于衡量硬件动画帧率。
